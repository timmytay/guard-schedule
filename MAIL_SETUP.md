# Почтовые уведомления Mail.ru

1. Установите зависимости: `python -m pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env`, замените `DUTY_EMAIL_MODE=console` на `DUTY_EMAIL_MODE=smtp`, введите пароль **приложения** Mail.ru в `DUTY_SMTP_PASSWORD`. Не публикуйте `.env`.
3. Выполните `python manage.py migrate`. Для пустой базы запустите `python manage.py duty_demo`.
4. В справочнике сотрудников укажите **реальные уникальные** email для всех пользователей, включая диспетчера.
5. Проверьте SMTP командой `python manage.py duty_test_email 1trofim.kraves@gmail.com`.
6. `python manage.py duty_tick` отправляет письма из очереди. Для автоматической работы запускайте команду раз в минуту в планировщике задач Windows. Не запускайте несколько экземпляров одновременно.

## Демонстрационные адреса

В демонстрационной базе каждому пользователю присваивается адрес вида `guard01@example.invalid` или `dispatcher@example.invalid`. При миграции существующей базы пустые email заменяются на уникальные `user<ID>@example.invalid`. Это **не реальные адреса**. Почтовая очередь их пропускает и не отправляет туда письма. После указания настоящих адресов новые уведомления отправляются автоматически.

## Важно

Отправка происходит только адресатам соответствующих событий. Внутренние уведомления остаются доступными независимо от SMTP. Если почтовый сервер временно не отвечает, `duty_tick` делает повторную попытку через 10 минут; после второй ошибки доставка помечается неудачной.
